## 3. The Full-Stack Architecture of a Capstone Feature

Your capstone feature must traverse the entire Android stack. Here is the reference architecture of a production-grade vertical slice:

```
+-----------------------------------------------------------------------------------+
| 1. Client App Layer (Kotlin / Java)                                               |
|    MainActivity -> EnterpriseSecurityManager.getHardwareEntropy()                  |
+-----------------------------------------+-----------------------------------------+
                                          | Context.getSystemService()
                                          v
+-----------------------------------------------------------------------------------+
| 2. Platform Framework Layer (system_server - UID 1000)                            |
|    EnterpriseSecurityService.java (extends SystemService)                         |
|      - Enforces permission: android.permission.ACCESS_HARDWARE_ENTROPY           |
|      - Calls Binder.clearCallingIdentity()                                        |
|      - Talks to HAL client proxy: aid::android::hardware::entropy::IEntropy       |
+-----------------------------------------+-----------------------------------------+
                                          | Treble Seam (/dev/binder IPC)
                                          v
+-----------------------------------------------------------------------------------+
| 3. Hardware Abstraction Layer (/vendor partition)                                 |
|    vendor.entropy-service (C++ or Rust AIDL HAL with @VintfStability)             |
|      - Declared in /vendor/etc/vintf/manifest.xml                                 |
|      - Enforced by SELinux: vendor_entropy.te                                     |
|      - Calls ioctl(fd, ENTROPY_GET_BYTES) on kernel device node                   |
+-----------------------------------------+-----------------------------------------+
                                          | VFS POSIX System Calls (/dev/entropy_hw)
                                          v
+-----------------------------------------------------------------------------------+
| 4. Linux Kernel Layer (EL1 / GKI ACK)                                             |
|    entropy_driver.c (Platform Character Driver matched via Device Tree)           |
|      - Binds to DT node: compatible = "acme,hardware-entropy"                     |
|      - Implements file_operations (unlocked_ioctl, read)                          |
|      - Safely copies data to userspace using copy_to_user()                       |
+-----------------------------------------------------------------------------------+
```

## 6. Configuring Cryptographic Commit Signing

Sign all commits in your Project Spine repository using SSH or GPG keys:

```bash
# 1. Configure Git to sign all commits by default
git config --global commit.gpgsign true
git config --global gpg.format ssh
git config --global user.signingkey ~/.ssh/id_ed25519.pub

# 2. Make a signed commit
git commit -S -m "capstone: Implement full-stack hardware entropy subsystem"

# 3. Verify signature locally
git log --show-signature -1
```

Once pushed to GitHub, your commits will feature the verified cryptographic badge:

```
[ Verified ] capstone: Implement full-stack hardware entropy subsystem
```
